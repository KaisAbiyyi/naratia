# Naratia

Game menulis cerita bersama. Cerita tumbuh per paragraf lewat ronde: pembaca membaca, mengutip, menangkap kesalahan kontinuitas, memilih, lalu pemenang menyambung narasi.

Branch ini (`v2`) adalah rebuild dengan SvelteKit + Supabase, di-deploy ke Vercel.
